# Examples

Repository examples are explanatory material. They do not define conformance,
change normative semantics or replace the fixture suites.

- [`ai-context/`](ai-context/): non-normative AI Context Profile `0.1.0`
  Projection examples.
- [`cross-domain/public-preview/`](cross-domain/public-preview/): final S7 P5
  standalone cross-domain learning examples, synthetic and validated offline.
- [`cross-domain/model-review.md`](cross-domain/model-review.md): historical
  cross-domain model review material.
- [`generic/`](generic/): generic example notes.
- [`json-provisional/`](json-provisional/): provisional JSON design examples.

When an example differs from the Foundation, an Accepted ADR, a normative
specification, Profile artifact or schema, the higher-authority artifact wins.
