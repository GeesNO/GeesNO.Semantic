# Larger bounded partial context

**NON-NORMATIVE ILLUSTRATIVE EXAMPLE**

## Purpose

Show a compact view over a moderately larger tabular observation source.

## Source scope

The source contains six row concepts and six value Assertions.

## Selection context

All twelve records are selected for the illustrative context request.

## Projection scope

The declared scope is the explicit twelve-record set, while the Projection
carries the first two rows and their values.

## Completeness

`partial`. The four-record bound was reached and truncation is established;
one known omitted material row is also declared explicitly.

## Material context decision

Provenance attached to the first row is carried exactly. The third row is
declared omitted rather than deleted or fabricated.

## Key distinction

`established truncation => partial`, while boundedness is not truth ranking,
importance or semantic priority.

## Files

- `source.json`: valid S2 tabular observation source.
- `projection.json`: bounded, truncated and partial Projection.

## Validation

The illustrative record counts are checked for internal consistency only; they
are not benchmark thresholds.

## What this example does NOT mean

It does not define a universal record limit, relevance ranking or I6 benchmark.
