# Changelog

This source distribution is pre-1.0. Released semantic contracts use explicit
versions independently from the distribution version. Documented breaking
changes remain possible before stable 1.0.

## [Unreleased]

### Available

- Universal Core model and exact JSON `spec_version` `0.1.0` representation.
- Vocabulary architecture and optional Base Vocabulary guidance.
- Optional AI Context Profile `0.1.0`, Projection and assessment bindings.
- Deterministic offline conformance corpora, including 58 assessment cases.
- Language-neutral implementation and conformance guides.
- Synthetic cross-domain examples and a non-normative Python reference SDK.
- Reproducibility benchmark recipes and expected artifacts.
- CC BY 4.0 specification/documentation and Apache-2.0 implementation licenses.

### Tooling

- Full-history identity handling is not a condition of semantic conformance.
- Distribution checks inspect locally supplied files and published artifact
  digests without requiring Git metadata or a remote service.

The planned Public Preview `0.1.0-preview.1` is not finalized. This changelog
does not publish a release or establish certification.
